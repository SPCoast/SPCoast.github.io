## cpNode IOX

16 bit I2C I/O Expander for MRCS cpNode system

Features
 - 23017 IO Expander
 - local 5v 750mA regulated power for attached accessories
 - 0.100 screw terminals for layout connections
 - I2C address display
 - Daisy chained 7.5c-12v DC unregulated power source feed through
